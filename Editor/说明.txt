NHT 解剖编辑器 · 操作手册
========================================

一、启动
--------
双击「启动编辑器.bat」。

- 只会出现一个控制台窗口，服务就直接跑在这个窗口里（不会再弹第二个窗口）；
- 浏览器会自动打开编辑器（地址形如 http://127.0.0.1:8765/anatomy-editor.html）；
- 端口 8765 被占用时会自动往后找（8766…8785），窗口里会打印实际地址；
- 关闭这个窗口 = 停止服务。

不要直接双击 anatomy-editor.html：
浏览器对 file:// 的限制很严 —— 读不到 PNG 像素（「贴合可见像素」失效）、
每次保存都要手动选文件夹。用本地服务打开才有完整功能。


二、界面总览
------------
左栏  01 体型画布    每张画布 = 一套独立的部位布局（一个体型 / 一个种族）
      02 部位结构    当前画布的部位树，按外形 / 器官 / 骨骼 / 眼睛 / 自定义分组
中间  画布           拖动部位、缩放、旋转，滚轮缩放视图，空格拖拽平移
右栏  全局 / 部位 / HAR / 素材 / 导出

顶部按钮：撤销 重做 | 历史 | 本地保存（全部画布） | 指南 · 通知 · 设置
右下角：↑回到顶部、参考发型悬浮窗（仅在「素材」页显示，默认收起为剪刀圆钮）


三、体型画布（左栏 01）
----------------------
· 分组：Default 放默认体型，Alien race 放导入的种族；底部「＋ 新建分组」可自建；
· 折叠：点分组标题展开/收起；
· 拖动：画布可上下排序，也能拖到别的分组标题/空白处完成归类；
· 未分组：不属于任何分组的画布显示在「未分组」里，可随时拖进分组；
· 右键画布：
    锁定 / 解除锁定（锁定后不能删除，条目会显示锁图标）
    移动到分组（可移出分组变「游离」）
    删除画布（红色，固定在菜单底部）
· 面板折叠：点标题前的 ▾ 折叠整块，状态会随项目保存。


四、部位编辑（右栏「部位」）
--------------------------
· 拖动部位移动，角上小方块缩放，上方圆点旋转；按住 Shift 拖动可自动对齐；
· 部位属性：
    部位         绑定的身体部位（编号 = 游戏使用的 NHT 槽位）
    贴图 / 变换  位置、缩放、旋转、翻转
    图层         0–29，数值大 = 盖在上面（输入超过 29 会立刻夹到 29）
    置顶重画     在所有部位和头发之后再补画一遍，永远在最上；
                 打开后有独立的「置顶等级」，最低也高于所有普通图层；
                 代价：会盖掉该部位原本的疤痕 / 伤口表现，建议只给装饰件用
    命中框       只能拖四个角改大小 —— 游戏里的判定框固定居中，所见即所得
· 拆卸：选中后按 Delete 或点「拆卸」，进左下托盘，可再装回或拖到别处。
· 对齐 / 排序 / 复制等操作在画布工具条与右键菜单里。


五、HAR 头发（右栏「HAR」）
--------------------------
两个开关：

· 发型重绘        在 NHT 画完头发之后再按参数补画一遍；
                  主要用途：让「非 HAR 发型」（原版 HairDef，如 RatKin / Wolfein）也能显示颜色；
· 导出发型坐标    把这套缩放 / 偏移 / 层级写进补丁（NHTCD_HairFit_*）；
                  关掉时游戏用默认值 0.78 / -0.21 / 15（头发会又大又偏下）。

联动：打开「发型重绘」会自动打开「导出发型坐标」；关闭时恢复它原来的状态。

参数：缩放 / 偏移X / 偏移Y / 层级（主层 + 后背层）、发色预览、锁定、后背层预览、
      跟随导出偏移、骨骼器官视图是否显示头发。

层级语义（重要）：
  头发会在「第一个 图层 ≥ 头发层级 的部位」之前绘制。
  所以 图层 > 头发层级 的部位会盖在头发之上（例如头发 14、耳朵 15 → 耳朵在上面）；
  图层 < 头发层级的会被头发盖住。

非 HAR 发型要显示颜色时的代价：
  重绘后的发色可能和默认的白发有偏差，位置也要逐层手动微调对齐；
  被头发盖住的部位需要单独打开「置顶重画」，而置顶重画会盖掉疤痕 / 伤口。

参考发型（右下角悬浮窗，素材页）：
  在素材里点一个发型即可放到头上做参考（对耳朵 / 角的位置用），可拖动、滚轮缩放，
  按住 Shift 拖动会自动对齐头部；「锁定」后不会被拖走；「图层 / 后层」只影响预览。
  它只是视觉参考，不会变成部位、也不会导出。


六、素材（右栏「素材」）
------------------------
· 导入素材 / 导入发型：从图片或整个模组文件夹导入（存在浏览器本地，刷新不丢）；
· 分类筛选、搜索，点贴图即添加到当前选中部位（或直接拖到部位上）；
· 发型分组上方有提示条；点一个发型会同时展开右下角的参考发型窗口；
· 「保存到 assets/」按钮已取消，素材随项目保存与导出流程处理。


七、导出（右栏「导出」）
------------------------
注入 INJECT
  · 单独注入模组    把**当前画布**写进 Patches/nht-<种族>.xml（并推送缺失贴图）；
  · 多选注入模组    打开勾选窗口：
        - 按分组列出画布，分组默认折叠；
        - 父勾选与子项联动（全选 / 半选 / 全不选）；
        - 改过的画布会自动勾上并标记「已修改」，其所在分组自动展开；
        - 「只选已修改」一键筛出需要重新注入的画布。

项目 PROJECT
  · 导出模组文件    导出**纯模组文件**（不含编辑器）：
        About/About.xml、Patches/nht-*.xml（按当前内容重新生成）、Textures/*.png；
        如果还有画布没注入，会先弹窗列出它们，确认后才继续；
  · 导出补丁 XML    只导出当前画布的补丁文本；
  · 导出项目 JSON / 导入项目 JSON / 导出画布 PNG（2×）。

校验 CHECK：错误 / 警告列表；下方是补丁预览，可复制。


八、保存与路径（顶部「设置」）
------------------------------
设置窗口（右上角橙色齿轮）：

· 保存前校验路径   开：每个保存动作都会先验证目标目录存在且可写；
                    关：不检查，失败直接报错；
· 每个保存按钮对应的路径都列在这里，右侧文件夹图标可手动指定目录：
      本地保存（全部画布 → nht-project.js）
      注入模组（单个 / 多选 → Patches/*.xml）
      贴图（Textures/）
      素材目录（assets/）
· 底部「放弃」= 不保存关闭；「保存」= 写入设置。

本地保存（全部画布）保存**整页数据**，不只是设置：
  全部画布与部位、发型参数、参考发型、素材清单、画布分组与折叠状态、
  面板折叠、当前分栏、缩放位置、保存路径设置等。

提示：设置窗口打开时，背景（含画布右上角警告徽标）会整体压暗并模糊。


九、指南 / 通知 / 提示（可自行编辑）
------------------------------------
全部放在 Editor\ui\ 目录：

  ui\guides.js    指南内容。格式：
                    window.NHT_GUIDES = [ { title: '标题', body: `<p>正文</p>` } ];
                  可用样式：<b class="g-opt">要设置的</b>（橙色）
                            <b class="g-bad">弊端 / 注意</b>（红色）
  ui\notice.html  右上角通知内容。用 <h2>/<h3> 或 <p class="nt-h"> 分段，
                  编辑器会自动做成可折叠子栏；内容有改动会重新提醒。
  ui\tips.html    画布底部轮播提示，每条 <div data-tip>…</div>。

未读提醒：通知 / 指南 / 帮助三个图标会黄色闪烁并轻微抖动；看过或内容更新才恢复。
通知只有点「收到」才会关闭；内容更新后会重新弹出。


十、文件与目录
--------------
anatomy-editor.html   编辑器本体（单文件，贴图内嵌）
nht-project.js        项目数据（画布 / 部位 / 发型参数 / 分组 / 设置 …）
ui\                   可自行编辑的文本：guides.js / notice.html / tips.html
assets\               素材贴图 + 清单 nht-art.js
serve.ps1             本地服务（含写盘接口）
stop-server.ps1       单独停止服务（一般不用，关窗口即可）
启动编辑器.bat         双击入口
安装新DLL.bat          更新模组 DLL 用
body-map*.json        游戏写出的 NHT 槽位对照表（用于「按对照表修正编号」/「同步游戏部位表」）
history\              本地保存的历史备份（保留最近 5 份）


十一、换新版 DLL
----------------
改了 Source\ 里的 C# 后：
  1. 运行 Source\build.ps1 编译；
  2. 完全退出游戏（游戏运行时 DLL 被占用，会写入失败）；
  3. 双击 Editor\安装新DLL.bat。


十二、日志与排查
----------------
Player.log 里本模组的几类信息：

  [NHT hair fit] race=… fitRace=… scale=… main=…
      实际用了哪套头发参数；fitRace=* 表示用了默认值（0.78 / -0.21）
  [NHT hair insert] race=… hairLayer=… insertedAt=layer…
      头发插入到哪个层级；出现「没找到插入点」说明所有部位层级都低于头发层级
  [NHT remap] <BodyDef> | 0->0:Torso …
      NHT 的槽位与身体部位对照（自定义身体由本模组现场生成）
  [NHT body order] <BodyDef> n=…
      身体部位顺序，用于生成 body-map 文件

常见问题
--------
· 头发巨大且偏下：没开「导出发型坐标」→ 用了默认 0.78 / -0.21。打开后重新注入即可。
· 耳朵被头发盖住：头发层级 < 耳朵层级时耳朵应在上；若仍被盖，检查头发层级是否要调小，
  或给耳朵打开「置顶重画」。
· 耳朵编号变成鼻子 / 下颚：画布存的是身体表下标而不是 NHT 槽位
  → 点「全局 → 按对照表修正编号」（没有对照表时按布局规则修正），或重新导入种族。
· 尾巴等 64+ 部位没有悬停文字：需要游戏生成对照表（进一次游戏写出 body-map），
  再在编辑器里点「同步游戏部位表」。
· 日志里 PatchOperationReplace … aboveParts failed：补丁引用了不存在的 HairFitDef。
  编辑器现在会自动避免；若还有，重新注入一次那张画布即可。
· 端口被占用：关掉旧的命令行窗口，或等它自动换端口。
· 模组内 Source\ 是 DLL 源码，与编辑器无关。

提示：改完项目先「本地保存」，再「注入模组」写补丁，重启游戏后生效。
