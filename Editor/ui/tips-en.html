If you can't move the hair or a part, try hiding the part that covers it first (click the eye icon in the left Part tree).
If part positions are off, click Visible box → hitbox first so the hitbox matches the visible pixels; selecting and dragging become much more accurate.
Each body canvas is now a separate file: Editor/canvases/<race>/<title>__<id>.json. Autosave only writes the current one, which is faster and easier to compare.
There is a green GIT bookmark on the right edge of the left Body canvases panel: open it to see the last 3 canvas versions in the repo; cards have thumbnails and can be applied to the project.
Clicking a card in the GIT bookmark is only read-only preview; to edit, click Apply on the card. The preview bar also has Apply / Back.
Recent changes under Body canvases remembers the last 5 replaced/deleted canvases; right-click the row to Restore.
In the push dialog, Editor/history, nht-project.js, *.bak and build outputs are locked by default (red) — they are personal data and would overwrite others.
While pushing, the button becomes Pushing… and shows a toast; the status bar, sync log and GIT bookmark refresh automatically.
Push changes = commit + push; the first push creates the branch on the remote. Pull remote = fetch others' new commits. "Unpushed" in REPO = commits + unpushed files (default-locked files excluded). The pull button glows with a red count when there are commits to pull.
You can use Git on another computer, but that computer needs Git installed and repo access; Settings → Git shows whether Git is available.
Save failures are usually wrong paths: open Settings → Save and run "Validate path before saving".
Export mod files creates the whole mod folder (without the editor): About / Patches / Textures; drop it into Mods and it works.
Hover anything with a hint to see a bubble tooltip (not the system yellow bar); long text wraps.
After editing, use Save all canvases, then single / multi inject; both steps are needed for the game to show the latest doll.
If GitHub is unreachable: the page still opens (REPO reads local cache); only Sync / Pull / Push go online; background checks give up after 8 seconds and never block the local server.
If several hair layers stack on the doll's head, the race mod registered multiple HAR addons. "Draw all hair layers" is off by default (main + back + one ahoge); turning it on restores drawing all layers.
Settings → About lets you upload/edit About.xml; it flags syntax errors, missing packageId, missing 1.6, etc. Export mod files ignores the mod's About.xml and uses the one saved here.
Default body canvases (Male / Female / Fat / Hulk / Kid) are not exported if their coordinates are unchanged; the game keeps NHT's original positions. To restore one: right-click the canvas → Restore NHT original coordinates.
Race patches include a BodyPartIndexesRemap: gills / tail / wings get slots after 64. The map prefers the game-written body-map-<body>.json; import a new race, enter the game once, and the editor gets the exact indices.

The dot button at the right of the top bar is the language switch: orange = 中文, blue = English. Switching updates the UI, tips and dialogs.
Canvases with xenotypes show a column of colored dots at the bottom-right: click a dot to preview that xenotype, click Base to reset; the small top dot collapses the rail.
Import xenotypes scans the mod for XenotypeDefs, HAR body Hediffs and hidden appearance Hediffs, then generates gene looks automatically. Appearance textures are auto-guessed first; replace them manually if wrong.
For bodyAddon colorChannel=hair parts such as ears and tails, turn on Hair color in the part properties to follow the pawn's current hair color; it is skipped when color is off.
The badge at the top-right is the canvas check: red = missing files or errors. Click it to see textures, grayscale, xenotypes and injection checks, and fix them from there.
With Canvas-pixel hitbox on, the in-game hitbox = canvas box / 512. Game Defs only have hitboxScale, so the hitbox is fixed centered.
Export offset only shifts export coordinates; the editor view stays the same. For stable positions, turn off Auto center and set the offset explicitly.
Turning on Export hair offsets in the Hair tab writes scale / offset / layer into the patch. Higher layers are on top; the back layer is always below all parts.
After editing, use Save all canvases, then single / multi inject. Both steps are needed for the game to show the latest doll.
The push dialog lists local changes first. Personal data (Editor/history, nht-project.js, *.bak, build outputs) is locked by default so it won't overwrite others.
Right-click a canvas card to combine selected cards or move to group. Groups keep related forms together.
The Assets category dropdown shows counts; the categories and groups next to the search box can be collapsed (collapsed by default).
