如果你移动不了头发或某个部位，不妨试试先隐藏掉覆盖在其上面的部位（左侧部位结构里点眼睛图标）。
部位位置对不上时，先点「可见框→命中框」让判定框贴合可见像素，之后点选和拖动都会准很多。
体型画布现在每张单独一个文件：Editor/canvases/<种族>/<标题>__<id>.json， 自动保存只写当前这一张，性能更好、也方便单独对比。
左侧「体型画布」面板右边缘有一枚绿色 GIT 书签：点开可以看仓库里最近 3 个画布版本， 卡片带缩略图，可以直接应用到项目里。
在 GIT 书签里点卡片只是只读预览，不能编辑；想改就先点卡片上的「应用」， 预览提示条里也会给「应用 / 返回」按钮。
「体型画布」下面的「最近改动」会记住最近 5 张被替换 / 删除的画布， 右键那一行只有「还原」，点错了随时能找回来。
推送弹窗里，Editor/history、nht-project.js、*.bak、编译产物等 会默认锁住（红色）—— 那是每个人本地的数据，推上去会覆盖别人。
推送时按钮会变成「正在推送…」并弹提示；成功后状态栏、同步日志、GIT 书签都会自动刷新，不用手点。
Git 分支别填 main：主分支不接受直接推送。用 feature-名字 这类分支，推上去再合并，主分支才安全。
换到别人的电脑上也能用 Git 功能，但对方要先安装 Git 并拥有仓库权限；「设置 → Git」顶部会显示本机 Git 是否可用。
保存失败大多是路径不对：打开「设置 → 保存」，先用「保存前校验路径」开关把它们检查一遍。
「导出模组文件」会打出整个模组文件夹（不含编辑器），About / Patches / Textures 都在里面，直接丢进 Mods 就能用。
界面上任何带提示的地方，鼠标悬停都会弹出气泡说明（不再是系统那种小黄条），内容长的会自动换行。
改完画布记得先「本地保存（全部画布）」，再「单独注入 / 多选注入」；两步都做了，游戏里才是最新的娃娃。
网络连不上 GitHub 时：页面照常打开（REPO 状态读本机缓存），只有点「同步 / 拉取 / 推送」才会联网； 后台检测最多 8 秒自动放弃，不会把本地服务卡住。
娃娃头上出现好几层头发叠在一起时：那是种族模组把多套发型都注册成 HAR addon。 模组设置里「画出所有发型层」默认是关的（只画一层主发 + 后发 + 1 个呆毛）；打开会恢复“全都画”的旧行为。
「设置 → About」可以上传 / 编辑 About.xml，页面会当场标出语法错误、缺 packageId、版本没写 1.6 等问题； 导出模组文件时忽略模组目录里的 About.xml，用这里保存的那份。
默认体型画布（标准男性 / 女性 / 肥胖 / 壮硕 / 幼体）如果没改过坐标，就不会被导出成补丁，游戏里继续用 NHT 自带的位置。 想把某张改回原样：右键画布 →「恢复 NHT 原始坐标」。
导出种族补丁时会自动附上「NHT 部位对照表」（BodyPartIndexesRemap）：腮 / 尾巴 / 翅这种种族多出来的部位 会排在 64 号以后的槽位。对照表优先用游戏写回的 body-map-<身体>.json； 新导入的种族先进一次游戏，编辑器就能拿到最准确的下标。

顶栏右侧的圆点按钮是语言切换：橙色 = 中文，蓝色 = English；切换后界面、提示和弹窗会一起更新。
有异种的画布右下角有一列彩色圆点：点圆点切换异种预览，点「基础」恢复；顶部小圆钮可以折叠。
「导入异种」会自动扫描模组里的 XenotypeDef、HAR body Hediff 和隐藏外观 Hediff，并自动生成基因外观；外观贴图会先自动猜图，猜错再手动换。
耳朵 / 尾巴这类 bodyAddon colorChannel=hair 的部位，在部位属性里打开「发色」就会跟随小人当前发色；关闭色彩时自动不染色。
画布右上角的徽章是画布检查：红色 = 有缺失 / 错误；点开可以看贴图、灰度、异种、注入等检查项，也能直接修复。
命中框开启「画布像素直出」时，游戏判定框 = 画布框 / 512；游戏 Defs 只有 hitboxScale，所以固定居中。
导出偏移只平移导出坐标，不改编辑器画面；想让位置稳定，关闭「自动居中」再把偏移写死。
发型页的「导出发型坐标」打开后，缩放 / 偏移 / 层级才会写进补丁；层级越大越靠上，后背层固定在所有部位之下。
改完画布先「本地保存（全部画布）」，再「单独注入 / 多选注入」；两步都做了游戏里才是最新的娃娃。
推送前会列出本地改动；个人数据（Editor/history、nht-project.js、*.bak、编译产物）默认锁定，避免覆盖别人。
画布卡片右键可以「选择卡片成组合」或「移动到分组」；组合用于把关联形态收在一起。
素材页的分类下拉带数量；搜索旁的分类和分组都能折叠，默认收起。
