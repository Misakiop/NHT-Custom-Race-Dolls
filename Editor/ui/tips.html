如果你移动不了头发或某个部位，不妨试试先隐藏掉覆盖在其上面的部位（左侧部位结构里点眼睛图标）。
画布右上角的徽章是 HAR 头发检测：红色三角 = 这个模组用了 HAR 头发但还没开自绘，点它可以直接跳过去开启。
部位位置对不上时，先点「可见框→命中框」让判定框贴合可见像素，之后点选和拖动都会准很多。
「项目」页现在是总出口：补丁、模组文件、项目 JSON、Git 同步都在这里。侧栏标签从「导出」改名叫「项目」了。
推送更改 = 提交 + push，第一次推会自动在远端建分支；拉取远端 = 把别人的新提交同步下来。 有未拉取的提交时，拉取按钮会发光并显示红点数字。
Git 分支别填 main：主分支不接受直接推送。用 feature-名字 这类分支，推上去再合并，主分支才安全。
换到别人的电脑上也能用 Git 功能，但对方要先安装 Git 并拥有仓库权限；「设置 → Git」顶部会显示本机 Git 是否可用。
保存失败大多是路径不对：打开「设置 → 保存路径」，先用「保存前校验路径」开关把它们检查一遍。
「导出模组文件」会打出整个模组文件夹（不含编辑器），About / Patches / Textures 都在里面，直接丢进 Mods 就能用。
界面上任何带提示的地方，鼠标悬停都会弹出气泡说明（不再是系统那种小黄条），内容长的会自动换行。
改完画布记得先「本地保存（全部画布）」，再「单独注入 / 多选注入」；两步都做了，游戏里才是最新的娃娃。
