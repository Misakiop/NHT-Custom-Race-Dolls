Nice Health Tab - Custom Race Dolls（NHT 自定义娃娃）
=====================================================

给 Nice Health Tab 的解剖面板换上自己画的娃娃 / 发型，并附带一个网页编辑器。
适用版本：RimWorld 1.7（1.6 需要单独编译 DLL，见文末第八节）。


一、这个模组做了什么
--------------------
DLL（Assemblies\NHT_CustomDolls.dll）挂了几处钩子：

1. 娃娃归类：启动时扫描所有 HumanlikeDoll，把 <xenotype> 等于种族 defName 的
   归到该种族名下；
2. 选娃娃：运行时给对应种族的棋子换上这套娃娃；未单独配置时按
   「默认 → 性别 → 体型 → 通配」回退，所以只做了女性体型时男女都用它；
   种族补丁里的娃娃如果都写成 Female，男性也会回退到它（不会变成没套用）；
3. 部位映射：种族 BodyDef 与人类不同时，按 BodyPartDef 名字自动生成槽位对照表；
   NHT 自己没给对照表的自定义身体，本模组会现场生成一份，
   所以 64 号以后的部位（尾巴等）也能画、也有悬停信息；
4. HAR 头发：HAR 附加件头发由本模组绘制，位置 / 缩放 / 层级来自补丁里的
   HairFitDef；头发画在「第一个 图层 ≥ 头发层级 的部位」之前，
   因此图层更高的耳朵会盖在头发上；
5. 非 HAR 发型上色：原版 HairDef 种族（RatKin / Wolfein 这类）开启「发型重绘」后，
   会按发色补画一层（副作用见第五节）。


二、Mod 设置（选项 → NHT 自定义娃娃）
------------------------------------
· 每个有种族娃娃的种族一行：默认 / 男 / 女 / 体型…
· 每一项都可以选：
    「自动（用种族补丁）」= 用该种族补丁里的娃娃（默认，推荐）
    种族补丁里的具体娃娃
    「基础 NHT 体型」里的 Male / Female / Fat / Hulk / Kid（原版体型）
· 页面顶部有一行说明：默认就是全部使用对应种族的补丁，只有手动改过的栏位才会变。
· 列表在启动时抓取，中途新增娃娃要重启游戏。


三、目录
--------
About\About.xml                 依赖与版本声明
Assemblies\NHT_CustomDolls.dll  上面这些钩子（改源码后跑 Source\build.ps1 重编）
Defs\                           本模组自带的 Def（默认发型参数等）
Patches\nht-*.xml               编辑器注入的种族娃娃补丁（一个画布一个文件）
Textures\                       编辑器推送的贴图（Custom\ 等）
Languages\                      中英文文本
Editor\                         网页编辑器（见 Editor\说明.txt）
  ├ anatomy-editor.html         编辑器本体
  ├ 启动编辑器.bat               双击启动本地服务并打开编辑器
  ├ nht-project.js              编辑器项目数据（画布 / 部位 / 发型参数 / 设置…）
  ├ ui\                         可自行编辑的 guides.js / notice.html / tips.html
  ├ assets\                     编辑器素材
  └ 安装新DLL.bat                更新 DLL 用
Source\                         C# 源码 + build.ps1


四、加一个种族
--------------
1. 双击 Editor\启动编辑器.bat（会开一个控制台窗口 = 本地服务，关窗即停止）；
2. 编辑器里「导入种族」选种族模组根目录，多个种族时会让你选；
3. 部位绑定：
     · 种族自带部位（翅膀 / 尾巴 / 角）→ 选它自己的序号；
     · 人类共有部位（头 13、耳 18/19、手 28/39…）→ 沿用 0–63，自动映射；
     · 纯装饰（不参与受伤）→ 「— 装饰」= -1；
4. 导出页 →「单独注入模组」写进 Patches\nht-<种族>.xml；多个画布可「多选注入模组」；
5. 重启游戏，新娃娃会出现在 Mod 设置里。


五、头发的两个开关（编辑器「HAR」页）
------------------------------------
· 导出发型坐标：把缩放 / 偏移 / 层级写进补丁。关掉会用默认值 0.78 / -0.21，
  头发会又大又偏下 —— 这是「头发突然变大」最常见的原因；
· 发型重绘：在 NHT 画完头发后再补画一层，主要用于让非 HAR 发型显示颜色。
  打开它会自动打开「导出发型坐标」。

副作用要知道：
· 被头发盖住的部位需要单独打开「置顶重画」，而置顶重画会盖掉该部位原本的
  疤痕 / 伤口表现，建议只给耳朵、角、头饰这类装饰用；
· 重绘出来的发色可能和默认白发有偏差，位置也要逐层手动微调。


六、导出与保存（编辑器「导出」页 / 设置）
----------------------------------------
· 单独注入模组   当前画布 → Patches\nht-<种族>.xml
· 多选注入模组   勾选多个画布一起写；改过的画布会自动勾上并展开所在分组
· 导出模组文件   把整个模组文件夹（不含 Editor）打包成 zip 下载，
                 已注入的 Patches、Assemblies、Defs、Languages、Textures、Source 都在里面
· 导出补丁 XML / 导出项目 JSON / 导出画布 PNG
· 顶部「设置」里有「保存前校验路径」开关，以及每类保存对应的路径与文件夹选择
· 顶部「本地保存（全部画布）」保存整页数据：所有画布、发型参数、分组、
  折叠状态、缩放位置、保存路径设置


七、重编 DLL
------------
如果你不知道怎么用，别动这个
powershell -ExecutionPolicy Bypass -File Source\build.ps1
然后完全退出游戏，双击 Editor\安装新DLL.bat（DLL 被占用时会写入失败）。


八、版本说明（重要）
--------------------
· 当前 DLL 是按 RimWorld 1.7 编译的（1.7 用 .NET 运行时，游戏根目录有 coreclr.dll）；


九、注意
--------
· 编辑器导出的补丁只处理对应画布；改完记得先「本地保存」再「注入模组」；
· 编辑器最好用本地服务打开（直接双击 html 也能看，但保存、像素检测会受限）；
· 日志里本模组的行：`[NHT hair fit]`、`[NHT hair insert]`、`[NHT remap]`、
  `[NHT body order]`，排查时看这几行即可。
